# Backend phase

## Goal
The AST (Abstract Syntax Tree) is generated by the parser, becomes the primary input for this backend phase. The goal is to transform the AST into a more compact representation, optimizing it for size while preserving the semantics of the original JavaScript code.

### Starting point
The AST represents the essential syntactic structure of the input program, abstracting away inessential details such as punctuation, delimiters, all forms of whitespace and comments. Because the AST inherently doesn't store these non-essential formatting elements, generating output directly from it will naturally result in a more compact representation. Thus achieving a basic level of minification. \
